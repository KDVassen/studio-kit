52 libraries and browser features are listed for selection, and 23 more are excluded with reasons. Three research agents gathered the data; every Core entry's licence file and latest release were then re-checked directly against GitHub and npm on the same day.

**How it was checked.** Licences come from each repo's LICENSE file, never a marketing page. Versions and dates come from the npm registry; stars and archive status from the GitHub API. Sizes are min+gzip, measured with esbuild where marked, otherwise from Bundlephobia. Reduced-motion behaviour was checked by searching each library's shipped source, not its docs. Anything not confirmed is marked `[UNVERIFIED]` in the agents' reports and kept out of this list's claims. Legal readings are not legal advice.

## Read before you pick

- **The browser does most of it now.** CSS scroll-driven animation, View Transitions and a 10-line reveal script cost 0 KB, and a reduced-motion setting stops all three. Reach for a library only when they cannot do the job.
- **One JavaScript animation library per project.** Motion, anime.js and GSAP overlap almost completely. Combining them adds 40 to 90 KB and three separate reduced-motion mechanisms to maintain.
- **GSAP is free to use, not yours to fork.** Its licence grants use only, with no right to modify, redistribute or sublicense, and the repo has no LICENSE file. Client contracts need to carve it out.
- **Only daisyUI and Basecoat work on every platform you are considering.** The React family is worthless on WordPress and costs JavaScript on Astro, so most of this list waits on your platform decision.
- **WordPress brings the GPL with it.** wordpress.org treats themes and plugins as derivative works under the GPL. That collides with keeping your reusable pieces under your own licence. Weigh it in the platform decision. This is a legal reading, not legal advice.
- **Fork only what you will change.** Four entries are worth forking: Basecoat, Accessible Astro Components, Mesh Gradient and Bklit. Install everything else from npm with a pinned version and list it in your reference repo.

## How to read the list

| Field | Meaning |
|---|---|
| **Core** | Likely on most builds: permissive licence, maintained, low to medium cost |
| **Situational** | Valuable for specific project types |
| **Reference-only** | Worth studying, not worth shipping |
| **Flagged licence** | Free, but not open source or carrying restrictions. The restriction is stated in the entry |

### daisyUI

- **What it is:** Pure-CSS component classes for Tailwind. No JavaScript.
- **Why it helps:** Works the same on Astro, Next.js and WordPress, ships zero JavaScript, and gates its own transitions behind reduced motion better than anything else checked. The safest default while your platform is undecided.
- **Licence:** MIT (Permissive). **Client hand-over:** Yes. Keep the MIT notice in the built CSS or a third-party notices file.
- **Latest:** 5.7.47 · 2026-09-30 · 42.5k stars · **Size:** CSS only; Tailwind emits just the classes you use. Never ship the full 97.7 KB file.
- **Accessibility:** 140 reduced-motion guards in its CSS. It styles native elements, so ARIA on tabs and dropdowns comes from your HTML.
- **Build cost:** Low · **Fork:** Reference only. Theme it with CSS variables instead.
- **Links:** https://daisyui.com · https://github.com/saadeghi/daisyui

### Basecoat

- **What it is:** The shadcn/ui look rebuilt in plain HTML, Tailwind and a little vanilla JavaScript.
- **Why it helps:** Gives clients the shadcn design language on WordPress or React-free Astro. Small enough to own outright, and with a single maintainer, a fork protects you if it stalls.
- **Licence:** MIT (Permissive). **Client hand-over:** Yes. Keep the MIT notice.
- **Latest:** 1.0.2 · 2026-07-06 · 4.3k stars · **Size:** JS 10.8 KB + CSS 21.9 KB gzip for every component; per-component files available.
- **Accessibility:** Manages aria-expanded, aria-selected and keyboard handling. No reduced-motion rules, so add one global rule.
- **Build cost:** Low · **Fork:** Worth forking. Small, framework-free, and you would adapt it into your house kit.
- **Links:** https://basecoatui.com · https://github.com/hunvreus/basecoat

### CSS scroll-driven animations

- **What it is:** CSS keyframes driven by scroll position or by an element moving through the viewport. No JavaScript.
- **Why it helps:** Replaces most of what people install ScrollTrigger or AOS for: scrubbed reveals, parallax, progress bars. 0 KB and no main-thread cost. Podium already uses it for its hero parallax.
- **Licence:** Web platform (Permissive). **Client hand-over:** Nothing to retain; it is the client's own CSS.
- **Latest:** Chrome 115+, Safari 26+ · **Size:** 0 KB
- **Accessibility:** A reduced-motion media query stops it completely. Gate with @supports so Firefox, which lacks it, gets static content.
- **Build cost:** Low · **Fork:** Not forkable. A browser feature; nothing to fork.
- **Links:** https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timeline

### View Transitions API

- **What it is:** Browser-native animated transitions between page states and between pages.
- **Why it helps:** Two lines of CSS give a static multi-page site page transitions without a router, the job Barba and Swup used to do. Browsers without support just navigate normally.
- **Licence:** Web platform (Permissive). **Client hand-over:** Nothing to retain.
- **Latest:** Same-page: Baseline. Cross-page: Chrome 126+, Safari 18.2+ · **Size:** 0 KB
- **Accessibility:** Browsers do not switch it off for reduced motion. You add one CSS rule.
- **Build cost:** Low for a fade, Medium for shared-element morphs · **Fork:** Not forkable. A browser feature.
- **Links:** https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API

### Reveal-on-scroll snippet

- **What it is:** About 10 lines of your own JavaScript that add a class when an element enters the viewport. CSS does the animation.
- **Why it helps:** Works everywhere including Firefox, replaces AOS and ScrollReveal in 227 bytes, and it is your own code: no licence, no dependency to keep updated. Keep it in your starter template.
- **Licence:** Your own code (Permissive). **Client hand-over:** The client owns it outright.
- **Latest:** IntersectionObserver, ~96% support · **Size:** 227 B gzip
- **Accessibility:** CSS does the motion, so the reduced-motion query stops it. Never hide the hero this way.
- **Build cost:** Low · **Fork:** Not forkable. Write it once; nothing to fork.
- **Links:** https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API

### GSAP

- **What it is:** The most capable JS animation platform: timelines, ScrollTrigger, SplitText, Flip, MorphSVG. Every plugin is now free.
- **Why it helps:** The fastest way to build Podium-level work for a rare premium client, and SplitText is the most accessible text splitter available. For ordinary business sites CSS covers most of it, and the licence complicates your handover.
- **Watch:** Not open source. Banned in no-code animation tools that compete with Webflow; Webflow may amend or terminate the terms.
- **Licence:** Webflow 'Standard No Charge' licence (Flagged). **Client hand-over:** The client holds it directly under Webflow's terms. Your contract must carve GSAP out of the 'modify, sublicense, transfer' clause. Keep every @license header.
- **Latest:** 3.15.0 · 2026-04-13 · 28.7k stars · **Size:** Core 27 KB; with ScrollTrigger 44.2 KB gzip.
- **Accessibility:** Nothing automatic; use gsap.matchMedia. ScrollSmoother ignores reduced motion entirely.
- **Build cost:** Medium · **Fork:** Not forkable. The licence grants use only. There is no right to modify or redistribute, and the repo has no LICENSE file.
- **Links:** https://gsap.com · https://github.com/greensock/GSAP

### Astro view transitions

- **What it is:** Astro's built-in router: app-like navigation with view transitions and fallbacks.
