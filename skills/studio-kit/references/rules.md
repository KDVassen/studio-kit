# Rules for client builds

Source: the studio knowledge base (`Website startup research/CLAUDE.md`, `13-brand-site_design-system-v2.md`, `14-brand-site_schematic-v2.md`, decisions D10–D13). Where this file and a client repo's own `CLAUDE.md` disagree, the client repo wins for that client.

## Hard rules

1. **Never** touch DNS, registrar settings, production hosting, billing or credentials without the operator's explicit approval in that session. Payment, DNS cut-over and launch are human-only.
2. **No secrets in git.** `.env` and `.dev.vars` in `.gitignore` before the first commit. Never paste tokens or keys anywhere.
3. **One private repository per client.** Never mix clients.
4. **No client data in any repo:** no database dumps, form submissions, or screenshots showing customer records.
5. **Dependencies:** nothing whose last release is older than 12 months; platform built-ins before packages; versions pinned; every dependency and version recorded for the handover.
6. **Forms:** server-side validation on every input; collect only what the purpose needs; honeypot and rate limiting before any CAPTCHA; **never collect health, medical or other special personal information** (exclusion E12).
7. **No keyed APIs** on brochure sites. Maps use the keyless iframe embed.
8. **No payments or checkout** (exclusion E2). Link to the client's own hosted gateway or booking app if needed.
9. Errors logged server-side, never shown raw to visitors.
10. **Third-party assets:** only licences that permit client use and transfer. Record name, version, licence and holder for every library, font, icon set and image.
11. **Human gate:** code touching personal data, file upload, database queries or payments is presented to the operator for line-by-line review before any deploy. Say so explicitly when it applies.
12. **Accessibility:** WCAG 2.2 AA is the floor.

## Content rules

- No fabricated reviews, testimonials, client names, logos, statistics, ratings or counts, **not even as layout placeholders**. Use a designed empty state.
- Concept or sample work is always labelled, as visible text, never only in alt text.
- Missing facts are visible placeholders in square brackets: `[PHONE]`, `[PRICE]`. Never invent a plausible value.
- **Displayed prices bind** under the Consumer Protection Act: show inclusions **and** exclusions next to every price; no "from" anchoring against a fixed price; no fake scarcity.
- No present-tense claims about things that do not exist yet.
- Write plainly. Avoid: solutions, leverage, empower, seamless, cutting-edge, passionate, revolutionise, game-changing, synergy, "our team" (for a sole operator), "trusted by".

## POPIA, for any site that collects personal information

- A notice **at the form** (s18): what is collected, why, that it is stored offshore if it is (Cloudflare), and a link to the privacy notice.
- The privacy notice names the responsible party and address, the purpose, that supply is voluntary, cross-border transfer and the vendors, the rights to object, access and correct, and the Information Regulator's contact details.
- **A reply to someone's own enquiry is not direct marketing.** No Form 4 checkbox on an enquiry form, and enquiry addresses never go onto a mailing list.
- **A mailing list is direct marketing (s69):** it needs a separate, unticked, Form-4-substantive consent checkbox, stored with timestamp, text version and source.
- A stated retention period for enquiries that do not become clients.
- The client is the responsible party for their site's data; the studio is an operator while it hosts or has access, which needs a written operator agreement (s21).

## Quality bars

| Area | Bar |
|---|---|
| Accessibility | WCAG 2.2 AA; contrast computed (4.5:1 text, 3:1 large text and UI borders); visible two-ring focus; targets ≥ 44×44 px; one `h1`; landmarks; skip link; `lang="en-ZA"` |
| Performance (mobile) | Lighthouse ≥ 95 every category; TBT ≤ 150 ms; CLS ≤ 0.02; LCP ≤ 2.0 s; JS ≤ 30 KB gzip per page; first load ≤ 450 KB. SEO applies to indexable pages only: noindex pages (404, thank-you) score low by design. Never remove noindex to raise a score |
| Motion | Reduced motion respected by every mechanism; no scroll-jacking; no autoplay without a pause control; nothing important animates into place |
| Privacy | No cookies; third-party requests limited to the analytics beacon, and disclosed; Worker invocation logs off so visitor IPs aren't kept |
| Security | Astro CSP on (no inline `style=""`, no `'unsafe-inline'`); `public/_headers` sets frame-ancestors, nosniff, referrer policy; the form accepts same-origin posts only |
| SEO | Unique title and description per page; canonical; Open Graph image; sitemap; robots.txt; JSON-LD without `aggregateRating` for self-hosted reviews |

## Handover outputs (every build)

- `docs/handover/dependencies.md`: every dependency with version (generated by `scripts/notices.py`)
- `THIRD_PARTY_NOTICES.md`: licence list and texts (generated), plus fonts, icons, images and copied source added by hand
- Completed launch checklist, on staging
- Notes for the handover document and the responsibility-transfer certificate
- The GSAP carve-out statement, if GSAP is used
